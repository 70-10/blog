# 用語集

このリポジトリ固有の語を 1 つに揃えるための用語集。同じ概念を別名で呼ぶとユーザーストーリーも設計もぶれるので、先に統一語を決める。

書式と規律は [記録の書式](recording-conventions.md) の「用語集」節にある。登録の要否は Inception / Construction の承認ゲートで決める。

---

**記事**（code: post）
このブログで公開されている 1 本の文章。
避ける別名: ポスト, エントリ, 投稿

**下書き**（code: draft）
まだ公開されていない、書き途中の文章。タイトルやタグが決まっていないこともある。
避ける別名: メモ, ネタ, ドラフト, 未公開記事
