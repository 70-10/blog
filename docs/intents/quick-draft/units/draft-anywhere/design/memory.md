## Interpretations

- 2026-08-13T09:03:59Z 「編集画面（自動保存）」を、入力が止まってから 3 秒でコミットする形と読んだ; `03_units.md` は自動保存と書くだけで間隔を定めていない。打つたびにコミットすると履歴が埋まり GitHub の API の回数も増えるので、待ちを入れた
- 2026-08-13T09:03:59Z US-03 の「手数 4 未満」を、Access のログイン済みの状態から数えるものと読んだ; ログインの Cookie が切れていれば手数が増えるが、切れる間隔は Access の設定によるので設計では確定できない。verify で実際に数える
- 2026-08-13T09:03:59Z `title` を「省略可」ではなく「常にあって空文字」と読んだ; US-01 は「タイトルを決めなくても保存できる」までしか言っていない。項目の有無と値の空の 2 通りで表すと判定が増えるので 1 通りにした

## Deviations

- 2026-08-13T09:03:59Z 下書きのコミットメッセージが Conventional Commits の形から外れる; `[CI Skip]` は先頭に置かないと Cloudflare Pages がデプロイを飛ばさないため、型がその後ろに来る（`[CI Skip] chore(draft): add <id>`）。`docs/rules/project.md` の定めから外れるが、管理画面が自動で打つものに限る

## Tradeoffs

- 2026-08-13T09:03:59Z 下書きを posts コレクションの外（`src/content/drafts/`）に置いた; 中に置いてフラグで絞る案と比べた。中に置くとスキーマの `title` / `publishDate` / `tags` の必須を外すことになり、緩和が既存 97 記事にも効いて記事ページ・RSS・OGP 画像がタイトルの無い記事を受けうる型になる。外に置けば `getPosts()` も `content.config.ts` も lefthook も触らない → ADR 0009
- 2026-08-13T09:03:59Z 下書きを `main` にコミットし、`[CI Skip]` でデプロイを飛ばした; 下書き専用のブランチにする案と比べた。ブランチを分けると公開のときにブランチをまたいでファイルを移すことになり、ADR 0004（着想から公開までを 1 つの変更として扱う）から遠のく → ADR 0009
- 2026-08-13T09:03:59Z 管理画面を `packages/admin` に置いた; `tools/admin` と比べた。`tools/` は手元で動く道具（`create-post` の CLI、Markdown の変換）の置き場で、配信されるアプリケーションは性質が違う。`pnpm-workspace.yaml` は既に `packages/*` を列挙しているので追記が要らない
- 2026-08-13T09:03:59Z 枠組みを Vite + React にし、Astro を使わなかった; ブログと同じ Astro で揃える案と比べた。管理画面は入力を受け続ける画面で静的な生成が要らず、ブログの Astro 設定を別プロジェクトに持ち込むと噛み合わない。React と Tailwind はリポジトリに既にあるので新しい枠組みは増えない
- 2026-08-13T09:03:59Z 識別子を時刻ではなく `crypto.randomUUID()` にした; 時刻を埋め込んで並び順に使う案と比べた。作成時刻は frontmatter の `createdAt` にあり、ファイル名にも入れると同じ事実が 2 か所になる。並び順は `updatedAt` で決めるので時刻の埋め込みは要らない
- 2026-08-13T09:03:59Z すでにある下書きを空にしたとき、保存せず最後の中身を残す形にした; 空を保存する案とファイルを消す案と比べた。空を保存すると「両方空の下書きは作らない」と食い違う状態が残り、消すと自動保存が黙って戻せない削除をすることになる。捨てるのは Unit 4 の明示的な操作
- 2026-08-13T09:03:59Z JWT の検証を `_middleware.ts` の 1 か所に置いた; 各経路に書く案と比べた。1 か所に集めれば、Unit 2 以降が経路を足したときに検証を忘れる余地がない
- 2026-08-13T09:12:00Z `_middleware.ts` の置き場を `functions/` の直下から `functions/api/` の下へ直した; ドキュメントで確かめたところ、根に置いたミドルウェアは静的なファイルの前でも動く。そのままだと JWT が無いことを理由に画面そのものが出なくなっていた。**設計を書いた時点では「/api/\* の手前」と書きながら、根に置く形になっていた**
- 2026-08-13T09:12:00Z `vitest.config.ts` の `coverage.include` への追加を、触るファイルの一覧に足した; `["src/**/*", "tools/**/*"]` に `packages/**` が無いことは explore で調べてあったのに、design の「触るファイル」から漏らしていた。テストの実行には影響しないがカバレッジの集計が漏れる
- 2026-08-13T09:03:59Z 一覧で 1 件ずつ中身を取りに行く回数（N+1）を受け入れた; 索引ファイルを持つ案と比べた。索引はファイルの中身と二重になり、ずれたときにどちらが正か決まらない。Unit 1 の一覧は件数が少ない前提で足りる。Unit 4 が冒頭の抜粋つきに育てるときに見直す
