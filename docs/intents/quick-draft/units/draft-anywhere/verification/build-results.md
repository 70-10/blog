## ビルド結果

### T8: 下書きを置いた状態

`src/content/drafts/` に 2 件を置いてから `pnpm build:local` を実行した。

| フィクスチャ                              | 中身                                                                                                                     |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `11111111-2222-4333-8444-555555555555.md` | タイトルあり。本文に目印 `DRAFT_MARKER_A`                                                                                |
| `99999999-8888-4777-8666-555555555555.md` | **`title: ""`**（記事のスキーマなら必須項目が欠けて落ちる形）。目印 `DRAFT_MARKER_B`。整形されていない箇条書きと表を含む |

| 確かめたこと                                    | 結果                                                  |
| ----------------------------------------------- | ----------------------------------------------------- |
| ビルドが通る                                    | **exit 0**。106 ページ（下書きが無いときと同じ）      |
| `dist/` に目印が出ない                          | **1 件も出ない**（`grep -rl 'DRAFT_MARKER' dist/`）   |
| `dist/` に下書きの識別子が出ない                | **1 件も出ない**                                      |
| 下書きの記事ページが作られない                  | `dist/posts/` は **97 件**。記事の実数（97 本）と一致 |
| `dist/rss.xml` に出ない                         | 0 件                                                  |
| `dist/index.html`（トップページの一覧）に出ない | 0 件                                                  |

**確かめ終えたあとフィクスチャは消した。** 残すと管理画面の一覧に偽の下書きが出続けるため（[test-cases.md](../test-design/test-cases.md) の T8）。

### `.prettierignore` の行が必要であることの確認

ADR 0009 は「`.prettierignore` に足さないと整形されていない下書きで CI が落ちる」と書いている。**両側で確かめた。**

| 状態                               | `pnpm prettier . --check` | 出力                                                      |
| ---------------------------------- | ------------------------- | --------------------------------------------------------- |
| `src/content/drafts/` を除外しない | **exit 1**                | `[warn] src/content/drafts/99999999-...md` と名指しされる |
| 除外する（現在の状態）             | exit 0                    | —                                                         |

**1 回目の確認は無意味だった。** 最初のフィクスチャがたまたま整形済みで、除外を外しても exit 0 だった。整形されない中身（箇条書きの記号・表の空白・行末の空白）に差し替えてから、はじめて両側の差が出た。
