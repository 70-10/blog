# 用語集・ADR・learn の記録は承認ゲートの固定枠で必ず行う

Status: accepted
発生元: ai-dlc-skills（AI-DLC スキルの移植）

このスキル群を先に運用していた別のリポジトリでは、用語集・ADR・learn の 3 つのうち実際に書かれていたのは learn だけだった。learn は全ステージの構造に組み込まれ承認ゲートの番号付き提示物に入っていたのに対し、用語集と ADR は「〜が出た場合は要否を確認する」という条件付きの注記としてゲートの外に置かれ、書くかどうかが AI の自己判定に委ねられていた。仕組みの種類ではなく置き場の問題なので、learn で実際に機能している形に 3 つとも揃える。Inception 4 ゲート・Construction 7 ゲートの計 11 ゲートすべてで、learn 候補・ADR 候補・用語の揺れをこの順で提示し、候補がゼロでも「残すことはありますか」を 1 問聞く。機械にできる候補の洗い出しは `.claude/scripts/` のスクリプトに寄せ、判断だけ人に残す。

却下した代替案: hook で機械的に止める — 最も強く、このリポジトリには既に PostToolUse hook があるので追加自体は難しくない。ただし容易さは採用の理由にならず、誤検出で作業そのものが止まるコストを、まだ効果を確かめていない段階で背負うことになる。ゲートの固定枠が実際に回ることを確かめてから、必要なら足す。
