# 無人実行では記録の判断を承認ゲートからレビューへ移す

Status: accepted
発生元: quick-draft（複数 Unit の自律実行）

[ADR 0001](0001-recording-fires-at-approval-gates.md) は、用語集・ADR・learn の記録を 11 の承認ゲートの
固定枠で必ず行い、候補がゼロでも 1 問聞くと決めた。複数の Unit を人が付かずに回す経路を足すと、そのゲートが
無くなる。無人実行のときだけ、判断の場所を移す。判定を満たすものは自動で書き、判定で書かなかった候補も
理由とともに `records.md` に残す。書いたものも書かなかったものも変更の中に現れるので、取捨選択は
レビューする人の手に残る。ADR 0001 は人が付いて回すときについて有効なままで、この ADR はその範囲を
無人実行の外に限定するもの。0001 を置き換えるわけではない。

却下した代替案: ADR 0001 を superseded にして記録の発火場所を一本化する — 人が付いて回すときのゲートは
今も機能しており、置き換えではなく範囲の限定が実態に合うため。

却下した代替案: 無人実行では記録しない — Unit を回すほど判断が失われる。記録の仕組みを持つ意味が
無人実行のぶんだけ薄れるため。

却下した代替案: 判定を満たすものだけ書き、書かなかった候補は残さない — 書かなかったものは変更の中に
現れず、レビューでも拾えない。ADR 0001 が防ごうとした「AI の自己判定で書かれないまま流れる」状態に
戻るため。
