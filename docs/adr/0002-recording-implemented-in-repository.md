# 記録機構はこのリポジトリ内で自前実装し、個人環境のスキルに委譲しない

Status: accepted
発生元: ai-dlc-skills（AI-DLC スキルの移植）

ADR を書く機能は個人環境（`~/.claude/skills/adr`）に既にあり、そちらのほうが Status の遷移や supersede の相互参照まで作り込まれている。しかしこのリポジトリは公開されていて、`.claude/skills/` に置くスキルも一緒に公開される。個人環境のスキルへ委譲すると、手元でしか動かないものを公開することになり、読んだ人が同じように動かせない。よって書式もロジックもリポジトリ内に置き、[記録の書式](../recording-conventions.md) を書式を定める唯一のファイル、`.claude/scripts/` を検出ロジックの置き場とする。書式はまだ ADR が 1 本も無い状態を踏まえ「まず書かれること」を優先して 1 段落と 3 行のヘッダに絞り、判定は 3 条件のゲートを維持する。

却下した代替案: 個人環境の `adr` スキルに執筆を委譲する — 書式・Status の運用・supersede の相互参照を自前で持たずに済み二重管理を避けられるが、公開したスキルが手元の環境に依存する。また既定が「セッション中の決定を全部拾う」で、3 条件で絞って増えすぎを防ぐ方針と逆を向いている。

却下した代替案: Context / Decision / Consequences / Alternatives Considered / References と索引ファイルを持つフル形式を採る — 情報量は最大だが、1 本も書かれていない状態で書くコストを上げると、書かれないままの状態が続くため。
